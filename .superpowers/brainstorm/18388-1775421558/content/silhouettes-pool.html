Pool de Silhuetas

6 silhuetas que alternam aleatoriamente a cada rodada. Todas renderizadas a ~8% opacidade no canvas.

Homem

Mulher

Criança

Robô

Alien

Super-herói

Cada silhueta é um componente SVG React em components/silhouettes/. O server sorteia o silhouetteId por rodada e envia pros dois jogadores para garantir que ambos vejam a mesma silhueta.
